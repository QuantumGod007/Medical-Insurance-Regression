# Medical Insurance Charge Prediction using Regression Models

## Overview

This project was developed as part of **Practical Assignment 03 – Performance Evaluation of Regression Model** for Artificial Intelligence and Machine Learning.

The main objectives of this project are:

1. To develop regression models for a real-world application and evaluate their performance using appropriate metrics.
2. To implement and analyze Gradient Descent optimization for Linear Regression.

The selected real-world application is **Medical Insurance Charge Prediction**, where medical insurance charges are predicted based on attributes such as age, sex, BMI, number of children, smoking status, and region.

## Performance Evaluation Metrics

The models are evaluated using the following regression metrics:

### 1. Mean Absolute Error (MAE)

MAE calculates the average absolute difference between actual and predicted values.

Lower MAE indicates better prediction accuracy.

### 2. Mean Squared Error (MSE)

MSE calculates the average squared difference between actual and predicted values.

It gives a larger penalty to large prediction errors.

### 3. Root Mean Squared Error (RMSE)

RMSE is the square root of MSE.

It represents prediction error in the same unit as the target variable.

### 4. R² Score

R² Score represents how much variation in the target variable is explained by the regression model.

A higher R² score generally indicates better model performance.

## Gradient Descent Implementation

Gradient Descent was implemented manually for simple Linear Regression.

For the Gradient Descent experiment:

- **Input Feature:** BMI
- **Target Variable:** Insurance Charges
- **Learning Rate:** 0.01
- **Number of Epochs:** 1000

The model follows the linear equation:

`y = wx + b`

where:

- `w` = Weight
- `b` = Bias
- `x` = BMI
- `y` = Predicted Insurance Charge

The parameters are updated using:

`w = w - learning_rate × dw`

`b = b - learning_rate × db`

The Mean Squared Error is calculated during every epoch to monitor convergence.

---

## Gradient Descent Results

The manual Gradient Descent implementation produced the following results:

- **Final Weight:** 2370.54
- **Final Bias:** 13346.09
- **Initial Loss:** 322451733.18
- **Final Loss:** 138714176.82
- **MAE:** 9784.65
- **MSE:** 149085057.01
- **RMSE:** 12210.04
- **R² Score:** 0.0397

The loss decreased significantly during training and eventually stabilized, demonstrating that the Gradient Descent algorithm successfully converged.

The R² score is relatively low because only **BMI** is used as the input feature in this simple Gradient Descent experiment, while medical insurance charges depend on several other factors.

---

## Learning Rate Analysis

To analyze the behavior of Gradient Descent, the following learning rates were tested:

- `0.001`
- `0.01`
- `0.1`

The learning rate controls the size of each update made to the weight and bias.

A smaller learning rate generally results in slower convergence, while a larger learning rate can reach the minimum faster. However, an excessively large learning rate may cause unstable updates or prevent convergence.

The loss-versus-epoch curves were compared to understand the effect of different learning rates on optimization.
